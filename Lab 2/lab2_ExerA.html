About The Workshop

Programming Workshop 2026 is an one-day event designed to help student improve their programming knowledge, coding skills and problem-solving abilities.

Guest Speaker: Syafiqah Elyana

An experienced Software Developer will share programming knowledge, industry experience and career opportunities in technology.

Hands-on Coding Activity

Participant will learn basic programming concepts and complete coding exercises using Java.
